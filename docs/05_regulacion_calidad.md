# 05 · Regulación (ICA) y calidad

> Norma base: **Resolución ICA 061252 de 2020** (registro de fabricantes y productos de alimentos para animales; trámite por la plataforma **SimplifICA**). Confirmar requisitos actualizados con la **seccional ICA Norte de Santander** antes de invertir.

## 1. Ruta regulatoria recomendada

| Paso | Modalidad ICA | Para qué |
|---|---|---|
| 1 | **Fabricante de alimentos para animales con destino al autoconsumo** | Fase 0/piloto: producir para la granja del hermano. Si se factura entre empresas distintas, probablemente ya no aplica autoconsumo; confirmar. |
| 2 | **Fabricante de alimento comercial para animales** + **registro de cada producto** | Fase 1: vender a terceros |
| 3 (opcional) | **Fabricante por contrato** (maquila) | Comprar iniciador peletizado maquilado o fabricar para terceros |

## 2. Requisitos principales (fabricante)

- Persona jurídica o natural con matrícula mercantil; RUT.
- **Asesor técnico** inscrito: médico veterinario, zootecnista o MVZ.
- Instalaciones adecuadas: pisos, paredes y techos sanitarios, iluminación, ventilación, drenajes, control de plagas y **áreas separadas** de materias primas, proceso y producto terminado.
- **Capacidad analítica:** laboratorio propio o contrato con laboratorio reconocido.
- Pago de tarifas ICA.

## 3. Registro de producto

Por cada SKU: nombre y especie, **composición garantizada** (mínimos y máximos de proteína, grasa, fibra, humedad, cenizas, Ca, P), fórmula cualicuantitativa, proceso, métodos de control y empaque. Por eso conviene **lanzar con un solo SKU**.

Valores sugeridos para la garantía (F2 con fitasa, con margen de seguridad):

| Parámetro | Calculado | Garantía sugerida |
|---|---:|---|
| Proteína cruda | ≈ 20,0 % | Mín. 19,0 % |
| Grasa (EE) | ≈ 6,8 % | Mín. 5,5 % |
| Fibra cruda | ≈ 2,9 % | Máx. 4,0 % |
| Humedad | — | Máx. 13,0 % |
| Calcio | 0,65 % | 0,55–0,85 % |
| Fósforo total | — | Mín. 0,45 % (calcular con laboratorio) |

## 4. Otros permisos

- Uso de suelo (POT del municipio), licencia o concepto de bomberos y seguridad y salud en el trabajo.
- Ambiental: consultar a **CORPONOR** por emisiones de polvo y manejo de residuos.
- Tributario: verificar con el contador el **tratamiento de IVA** del alimento para animales (partida 23.09), porque afecta el precio y el flujo de caja.

## 5. Sistema de calidad mínimo (BPM)

1. Recepción con **ficha de inspección** por carga (humedad, olor, insectos, aflatoxina en maíz, peso).
2. **Orden de producción por batch** con pesos reales firmados (sobre todo de los microingredientes).
3. **Lote** impreso en cada bulto. La trazabilidad va de proveedor a cliente.
4. Muestra de retención por lote (3 meses).
5. Análisis mensual de laboratorio por SKU contra la garantía.
6. Limpieza y control de plagas documentados.
7. Quejas y devoluciones registradas, con su análisis de causa.
